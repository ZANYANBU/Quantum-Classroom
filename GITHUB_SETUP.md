## GitHub Pages (Optional)

If you want to deploy the frontend via GitHub Pages:

1. Go to Settings → Pages
2. Source: Deploy from a branch
3. Branch: `gh-pages` (create after setting up deployment)
4. Folder: `/` (root)

**Note**: For full functionality, you'll need to deploy both frontend (Vercel/Netlify) and backend (Railway/Render) separately.

## Repository Labels

Recommended labels for issues:

**Type:**
- `bug` - Something isn't working
- `enhancement` - New feature or improvement
- `documentation` - Documentation improvements
- `question` - Further information requested
- `experiment` - New experiment suggestion

**Difficulty:**
- `good first issue` - Good for newcomers
- `help wanted` - Extra attention needed
- `beginner` - Beginner-friendly quantum concepts
- `advanced` - Advanced quantum algorithms

**Area:**
- `frontend` - Next.js/React/UI issues
- `backend` - FastAPI/Python issues
- `qiskit` - Quantum computing/Qiskit issues
- `education` - Educational content/pedagogy

**Priority:**
- `priority: high` - Critical issues
- `priority: medium` - Important improvements
- `priority: low` - Nice to have
